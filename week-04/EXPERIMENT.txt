W4｜给追加实验保留独立方案

背景与目的
你已用蒲丰投针生成一版论文图表。导师要求保留旧参数，换随机种子并
调整一组投针数，追加实验；还要从相同参数生成两份候选，分别继续调整。
起始内容可以相等，后续修改不能互相串扰。
实现配置生成函数，将维护要求交给测试。代码可以由 Agent 编写，
你负责解释预期依据，亲自核验测试与实际改动。
不重写投针算法、不修改 W3 报告，不以 π 估计更准确作为验收。

固定入口
    variant.py: make_variant(source, seed, index, replacement)

输入
source 是普通字典，含整数 seed 和非空正整数列表 sample_sizes。
本题配置只含这两个字段。
seed 是新随机种子；index 是要更新的位置（从 0 开始）；
replacement 是该位置新的正整数样本量。输入和位置均合法。
不要求处理非法输入，不要求任意复杂对象的通用深复制。

五项承诺
1. 返回新方案：更新 seed 与 sample_sizes[index]，其余内容保持。
2. source 保持调用前的内容。
3. 返回字典与 source 不同；返回的 sample_sizes 与原列表不同。
4. 后续修改返回结果，不影响 source。
5. 相同参数调用两次：内容相等，字典和列表身份分别不同；
   修改第一份，不影响第二份和 source。
不可变整数不需要拥有不同身份。

已知例子
source = {"seed": 42, "sample_sizes": [1000, 10000, 100000]}
参数为 seed=2026, index=2, replacement=500000
返回应为 {"seed": 2026, "sample_sizes": [1000, 10000, 500000]}
source 仍为 {"seed": 42, "sample_sizes": [1000, 10000, 100000]}

学生与 Agent 的必做
- 另选一组合法输入，先预测结果、== 和 is，再写 tests/test_student.py。
- 测试参数接收课程 fixture make_variant，不直接 import 候选函数。
- 预期与旧内容快照独立建立，不用 before = source 保存旧内容。
- 同一份学生测试接受 reference，拒绝 direct 与 shallow 的共享故障。
- 实现 variant.py，本人运行学生测试与教师公开验收。
- 对一条断言说明比较对象、预期依据、能拒绝的错误；在源码找到
  独立字典、独立列表与指定修改的位置，保留简短实际证据。

允许修改
variant.py、tests/test_student.py；可另存自己的实验与记录。
不修改 examples.py、tests/conftest.py、tests/test_acceptance.py 来获得通过。
本周环境直接提供，不改 W2/W3 的配置、锁文件或已有成果。

选做
新 seed 和 replacement 与原值相同。先用内容比较观察直接共享故障，
再用身份或后续修改拒绝它，解释“这次没改坏”和“可独立维护”的区别。
这不是新接口；参数不变时，公开的独立性承诺仍成立。
